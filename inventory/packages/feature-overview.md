# Packages – Feature Overview

## 1. Overview

Packages are used to group one or more products into a physical or logistical unit for storage, handling, transportation, and inventory operations.

A package can contain different products or quantities of products, allowing them to be managed together rather than handling every item individually.

For example, several spare parts can be grouped into one package for storage or transfer between warehouse locations.

## 2. Package Information

A package generally contains information such as:

- **Package Reference:** Unique identification of the package.
- **Package Type:** Classification of the package.
- **Location:** Current storage location.
- **Company:** Company associated with the package.
- **Owner:** Ownership information where applicable.
- **Package Contents:** Products and their quantities contained in the package.

## 3. Package Operations

Packages support inventory handling activities, including:

- Creating and identifying packages.
- Organizing products within packages.
- Viewing package contents.
- Tracking package locations.
- Transferring packages between locations.
- Unpacking products when necessary.

## 4. Package Transfers

Package transfers involve moving packages or their contents from one location to another.

A transfer generally identifies the source location, destination location, products involved, and scheduled transfer information.

This helps organizations manage the movement of packaged items between warehouse locations while maintaining inventory records.

## 5. Purpose and Benefits

Packages help organizations:

- Group products for easier handling and storage.
- Identify and manage packaged inventory.
- Simplify internal warehouse operations.
- Support the movement of packaged items.
- Improve visibility into package contents and locations.

Packages therefore provide an additional way to organize and manage physical inventory during warehouse operations.
